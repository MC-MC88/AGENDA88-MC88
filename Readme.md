## 👋 Bienvenue

agenda88 est un fichier HTML unique. Il affiche un calendrier mensuel. Vous cliquez sur un jour, vous ajoutez un titre et une description, et l'événement est enregistré dans votre navigateur. Aucun compte, aucun serveur.

---

## ✨ Ce que vous trouverez

**Calendrier mensuel.**  
Navigation entre les mois avec deux boutons. Chaque jour affiche son numéro. Un point signale les jours qui contiennent des événements.

**Ajout d'événements.**  
Cliquez sur un jour pour ouvrir une fenêtre. Saisissez un titre et une description. Le titre est obligatoire, la description est optionnelle.

**Suppression d'événements.**  
Chaque événement affiché propose une icône de suppression. Un clic retire l'événement de la journée.

**Dix thèmes visuels.**  
Cream, Midnight, Sepia, Ocean, Forest, Sunset, Lavender, Mono, Blossom et Neon. Chaque thème change les couleurs, les polices et les formes.

**Fond aléatoire.**  
À chaque chargement, une image de fond différente est choisie via Picsum. L'image est atténuée par une couche de couleur.

**Sauvegarde locale.**  
Les événements et le thème choisi sont conservés dans le stockage local du navigateur.

**Jour actuel mis en valeur.**  
Le jour de la date du jour est entouré et animé, avec une animation discrète qui s'adapte au thème Neon.

**Mise en page adaptée au mobile.**  
La grille, les boutons et la fenêtre se redimensionnent automatiquement pour les petits écrans.

---

## 🧭 Comment ça marche

**1. Ouvrez la page.**  
Le calendrier du mois en cours s'affiche.

**2. Cliquez sur un jour.**  
Une fenêtre s'ouvre avec les événements du jour.

**3. Ajoutez un titre.**  
Remplissez le titre, puis la description si besoin. Cliquez sur « Save Event ».

**4. Changez de thème.**  
Cliquez sur le bouton rond en haut à droite. Le thème change à chaque clic.

C'est tout. Vos événements restent dans votre navigateur.

---

## 🛠️ Petits coups de main

**Où sont stockés mes événements ?**  
Dans le stockage local de votre navigateur, sur votre appareil uniquement. Rien n'est envoyé en ligne.

**Puis-je utiliser l'application hors ligne ?**  
Oui, une fois la page chargée. Les événements fonctionnent hors ligne. Seules les images de fond nécessitent une connexion.

**Comment changer de thème ?**  
Cliquez sur le bouton en haut à droite. Un clic fait passer au thème suivant. Le thème choisi est mémorisé.

**Que se passe-t-il si je vide le cache du navigateur ?**  
Vos événements et votre thème seront supprimés.

## 👋 Welcome

agenda88 is a single HTML file. It shows a monthly calendar. You click a day, you add a title and a description, and the event is saved in your browser. No account, no server.

---

## ✨ What you'll find

**Monthly calendar.**  
Navigation between months with two buttons. Each day shows its number. A dot marks days that contain events.

**Adding events.**  
Click a day to open a window. Enter a title and a description. The title is required, the description is optional.

**Deleting events.**  
Each listed event has a delete icon. One click removes the event from the day.

**Ten visual themes.**  
Cream, Midnight, Sepia, Ocean, Forest, Sunset, Lavender, Mono, Blossom and Neon. Each theme changes colors, fonts and shapes.

**Random background.**  
On each load, a different background image is chosen via Picsum. The image is softened by a color layer.

**Local save.**  
Events and the chosen theme are kept in the browser's local storage.

**Today highlighted.**  
The current day is outlined and animated, with a subtle animation that adapts to the Neon theme.

**Mobile-friendly layout.**  
The grid, buttons and window resize automatically for small screens.

---

## 🧭 How it works

**1. Open the page.**  
The current month's calendar appears.

**2. Click a day.**  
A window opens with the day's events.

**3. Add a title.**  
Fill in the title, then the description if needed. Click "Save Event".

**4. Change the theme.**  
Click the round button at the top right. The theme changes on each click.

That's it. Your events stay in your browser.

---

## 🛠️ A little help

**Where are my events stored?**  
In your browser's local storage, on your device only. Nothing is sent online.

**Can I use it offline?**  
Yes, once the page is loaded. Events work offline. Only the background images need a connection.

**How do I change the theme?**  
Click the button at the top right. One click moves to the next theme. The chosen theme is remembered.

**What happens if I clear my browser cache?**  
Your events and theme will be deleted.
